# SkillSync AI - Student, Recruiter & Admin Portal

SkillSync AI is a next-generation career platform bridging the gap between students and top companies using intelligent matching algorithms, automated resume scoring, and AI interview coaching.

## Features
- **Student Portal**: Resume Upload (PDF), AI ATS Scoring, Skill Gap Analysis, Interactive Learning Roadmaps, AI Interview Coach (voice-to-text capable), and a comprehensive Job Application Tracker.
- **Recruiter Portal**: Post and manage jobs, review AI-shortlisted candidates, Applicant Tracking System (ATS), and recruitment analytics.
- **Admin Portal**: System-wide platform moderation, User/Company verification, platform analytics, and global settings.

## Tech Stack
- **Frontend**: React (Vite), Tailwind CSS, Framer Motion, Axios, React Router, Chart.js.
- **Backend (Expected)**: Spring Boot, PostgreSQL, JWT Authentication.
- **AI Integrations (Expected)**: Google Gemini (Resume parsing, Coaching, Roadmaps).
